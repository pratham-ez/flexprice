# Users

## Overview

### Available Operations

* [createServiceAccount](#createserviceaccount) - Create service account
* [getWithMe](#getwithme) - Get user info
* [search](#search) - List service accounts with filters

## createServiceAccount

Create a new service account with required roles. Only service accounts can be created via this endpoint.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="post_/users" method="post" path="/users" -->
```typescript
import { Flexprice } from "@flexprice/sdk";

const flexprice = new Flexprice({
  serverURL: "https://api.example.com",
  apiKeyAuth: "<YOUR_API_KEY_HERE>",
});

async function run() {
  const result = await flexprice.users.createServiceAccount({
    roles: [],
    type: "service_account",
  });

  console.log(result);
}

run();
```
